# prompt.md


Build me a polished iPhone app in SwiftUI called “Yearbook” (or “My Year Scrapbook”), a digital scrapbook app organized by year.

Before writing code:
- Review the app requirements
- Propose a clean project structure
- List the models, screens, and architecture you will use
- Then implement the project file by file

App concept:
This app should let users create a scrapbook for each year of their life. Each year acts like its own digital scrapbook with journal entries, photos, favorites, goals, highlights, and monthly recaps.

Features:
- Home screen with scrapbook covers for each year
- Create, edit, and delete years
- Journal entries with title, body text, date, mood, tags, and photos
- Favorites section
- Search by keyword, tag, month, or year
- Timeline or memory feed
- “On This Day” feature
- Locked/private entries
- Year highlight summary page

Design:
- Cozy scrapbook aesthetic
- Soft, feminine, nostalgic look
- Rounded cards, layered paper feel, cute icons, gentle animations
- Clean and polished iOS design

Technical requirements:
- SwiftUI
- MVVM
- SwiftData preferred for persistence
- Beginner-friendly code
- Modular file structure
- Include mock/sample data
- Make sure it compiles

Please output:
1. Project structure
2. Models
3. ViewModels
4. Views
5. Sample data / preview support
6. Final setup instructions

Make thoughtful choices where needed and keep the code easy to expand later.
